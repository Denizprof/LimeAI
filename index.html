Voice assistant · runs on your PC

Say “Hey Lime.”
Your voice and your AI stay on your PC.

Lime is a Jarvis-style desktop assistant with a wake word, ~90 voice commands, a live world-data dashboard, and a memory that actually persists — speech recognition and language model both running on your own machine. Weather, news, and Spotify still need the internet, same as any app that talks to those services.

Memory

Nothing said once is gone by the next session.

Three separate systems, so nothing has to be repeated: durable personal facts, a searchable permanent conversation log, and a knowledge base you control.

Facts"remember this — I'm allergic to peanuts" · "what do you remember about me?"
Durable personal facts, saved forever across restarts. Lime also auto-saves facts it notices in passing, without being told to — it doesn't wait for "remember this" every time.
Conversation log"what did we talk about today?" · "what have we talked about?"
Every real exchange is logged with a date, time, and guessed topic, forever — and is actually searched and fed back into the AI's context when relevant, not just stored and forgotten.
Knowledge base"add to my knowledge base: ..." · "what's in my knowledge base?"
A user-editable library — paste in notes, reference docs, anything past the model's training cutoff — that Lime searches and cites when it's relevant to what you asked.
Profile"build my profile"
Synthesizes everything remembered, logged, and stored into one written profile — confirmed facts separated from inferred ones — saved back into the knowledge base.
Where it's stored
On your disk
Plain local files — no account, no cloud sync, nothing leaves the machine to be remembered.
How it's found
Keyword search
No black-box embeddings — matches are score-ranked by shared words, so what gets surfaced is explainable.
Undo
"Forget everything"
One phrase clears saved memories, any time you want a clean slate.

Local-first, by design

The model can talk. It can't act.

Real actions — opening apps, setting reminders, controlling devices — are handled by deterministic pattern matching, never improvised by the language model. Voice recognition and reasoning both make mistakes; giving that combination unchecked execution power was a deliberate no.

FAQ

Common questions

The things people actually ask before installing a voice assistant that lives on their desktop.

Does Lime send my voice or data anywhere?
No, by default. Speech recognition (Whisper) and reasoning (Ollama) both run locally on your machine. The only outbound requests are for things that are inherently online — weather, news, Spotify search — and none of those carry your voice.
Is it free?
Yes. No account, no subscription, no login screen.
What are the system requirements?
Windows 10 or 11, 8GB RAM minimum (16GB+ recommended if you want the larger local language model), and a microphone. A GPU speeds up responses but isn't required.
Can it actually control my computer?
Within a fixed, deterministic command set — yes: opening apps and files, media/volume control, screenshots, smart-home devices, reminders. It will never improvise a system action from a guess; anything outside its known commands gets a spoken answer, not an attempted action.
Does it work without internet?
The core assistant does — wake word, transcription, and open-ended conversation all run offline. Weather, world news, and smart-home pairing need a connection, same as any app that talks to those services.
Can I automate it with other tools?
Yes — Lime runs a small local API (key-protected, bound to your own machine) that tools like n8n can call to ask it questions or trigger real commands.
Can I change the wake word?
Yes — it defaults to "Lime" but you can set it to anything in Settings. Wake-word matching is fuzzy (tolerant of accents and mishearing), not an exact string match.
What languages does it understand?
English, Russian, and Turkish. You need to set the language in the "Speak" dropdown before talking — speech recognition doesn't auto-detect per utterance, so the wrong setting produces garbled transcription.
Can I delete what it remembers about me?
Yes — say "forget everything" and saved facts are cleared immediately. There's no hidden backup copy kept anywhere.
Does it run on Mac or Linux?
Not currently — Lime is Windows-only (10/11). Several of its system commands (screenshots, Wi-Fi status, now-playing info) use Windows-specific APIs directly.

About

Built by one person, for their own desk.

Lime isn't a company product — it's a solo, ongoing build, made by someone who wanted a voice assistant that actually respected the "local-first" part.

D
Denizprof — Daniel
Teenage solo developer

Hi, I'm Daniel. I build Lime by myself, on my own time — it's not a company or a team, just a personal project I've kept pushing on. It started as an experiment to see how far a fully local, privacy-respecting assistant could go with no cloud LLM, no account, and no telemetry, and it's grown one real feature at a time from there: persistent memory, a live world-data monitor, an honest deterministic command system, and most recently Flow State.

The "real, not fabricated" rule that runs through this whole site is mine: real Windows Defender instead of a fake scanner, real USGS/BBC/NASA feeds instead of invented news, real deterministic pattern matching instead of letting a language model improvise system actions.

I use Claude, Gemini, ChatGPT, and a few other AI models and tools to help me build faster — but every design decision, every architecture choice, and everything Lime looks and feels like is mine. AI is a tool I use, not the thing doing the building. I'm the one deciding what Lime becomes.
